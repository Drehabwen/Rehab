# Rehab 用户旅程图 (User Journey Map)

> 基于 UX 分析绘制 | 更新日期: 2025-02-16

---

## 一、用户画像

| 属性 | 描述 |
|------|------|
| **角色** | 康复科医生 / 物理治疗师 |
| **目标** | 快速评估患者体态，生成专业报告 |
| **场景** | 门诊接诊、康复评估、随访记录 |
| **痛点** | 传统测量耗时长、数据难以量化对比 |

## 四、关键触点总结

| 触点 | 用户目标 | 核心功能 | 情绪 | 改进方向 |
|------|----------|----------|------|----------|
| **Dashboard** | 快速开始工作 | 接诊入口、历史记录 | 😐 中性 | 简化信息层级 |
| **EntryHub** | 选择合适模式 | 模式介绍、视角选择 | 🙂 期待 | 增加摄像头预览 |
| **CameraStage** | 采集准确数据 | 实时检测、引导拍摄 | 😤 专注 | 增加站位引导 |
| **Analysis** | 获得分析结果 | AI 处理、进度反馈 | 😐 等待 | 优化等待体验 |
| **Report** | 输出专业报告 | 指标展示、PDF 导出 | 😊 满意 | 增强报告专业性 |
