# 家长版运动处方说明层

Last verified: 2026-06-01

## 目标

康复师下达的运动处方仍然是唯一专业依据。家长端需要的是一个“执行说明层”：把专业处方拆成家长能理解、能执行、能反馈、能判断风险的说明，而不是重新生成新的治疗方案。

V1 的目标是让家长一进入训练页，就能回答四个问题：

- 今天要做什么。
- 每个动作为什么做、怎么做、做多少。
- 出现什么情况要暂停。
- 做完以后要反馈什么。

## 核心原则

- `plan_content` 是康复师原始处方，必须保留并可查看。
- 家长版说明只能解释和结构化，不能擅自改变动作、剂量、频次、禁忌和安全边界。
- 家长端默认展示家长版说明，同时提供“康复师原始处方”折叠入口。
- 生成失败时降级展示原始处方，并提示按康复师说明执行。
- 后续家长反馈继续绑定同一个 `patient_id` 和对应 `plan_id`。

## 用户旅程

```mermaid

  A["康复师下达运动处方"] --> B["后端保存原始 plan_content"]

```

## 数据契约

`translated_plan_content` 当前作为 JSON 字符串挂在治疗计划响应上。推荐结构如下：

```ts
interface ParentPlanExplanation {
  parent_title: string;
  today_focus: string;
  estimated_minutes?: number;
  exercises: Array<{
    name: string;
    purpose: string;
    how_to_do: string[];
    dosage: string[];
    cautions: string[];
    child_tips: string[];
  }>;
  stop_conditions: string[];
  contact_therapist_when: string[];
}
```

字段约定：

- `parent_title`：家长可理解的训练标题。
- `today_focus`：今天训练重点，不能夸大成诊断或疗效承诺。
- `estimated_minutes`：估算执行时间，用于首页摘要。
- `exercises`：只能来自康复师原始处方或明确可解析的动作条目。
- `dosage`：保留原处方里的组数、次数、时长、频次表达。
- `stop_conditions` 和 `contact_therapist_when`：必须保守，不能弱化原始风险提示。

## 生成策略

灰度前采用“规则兜底优先，LLM 辅助润色”的策略：

- 规则层提取动作名、组数、次数、时长、频次和注意事项。
- 模板层稳定输出目的、做法、剂量、注意事项和孩子不配合时的处理。
- LLM 只做语言解释和家长化表达。
- LLM 输出必须保留原始动作名和剂量，不允许新增训练动作。
- 没有 LLM key 或生成失败时，后端返回规则生成的结构化说明。

## 家长端展示

首页训练卡片：

```text
今日训练重点
帮助孩子按康复师处方完成家庭训练。
今天有 3 个动作，预计 15 分钟。
查看家长版说明
```

训练详情页：

```text
动作 1：猫牛式

为什么做：帮助孩子活动背部，减轻久坐后的僵硬感。
怎么做：
1. 双手双膝支撑在垫子上。
2. 慢慢拱背，再慢慢塌腰。
3. 动作过程中不要憋气。
做多少：每组 8 次，做 2 组。
注意：不要追求幅度过大。如疼痛明显加重，先暂停。
```

安全提示：

```text
如果出现明显疼痛加重、头晕、麻木、孩子强烈抗拒，请暂停训练并联系康复师。
```

## 禁止行为

- 不允许把家长版说明说成“新的治疗方案”。
- 不允许 AI 自行调整训练剂量。
- 不允许删除康复师写明的禁忌和注意事项。
- 不允许用诊断口吻解释训练目标。
- 不允许在家长端隐藏原始处方。

## V1 实现范围

已纳入 V1：

- 后端 `/api/integration/plan/push` 生成 `translated_plan_content`。
- 后端无 LLM key 时使用规则模板兜底。
- C 端训练页和处方页展示家长版说明。
- C 端首页训练卡片使用家长可读摘要。
- 原始康复师处方以折叠区保留。

暂不纳入 V1：

- 微信模板消息推送。
- 视频动作库。
- 个性化难度自动调节。
- 自动修改康复师处方。
- 多轮 AI 追问生成新训练计划。

## 验收标准

- 家长不需要理解康复专业术语，也能知道今天怎么做。
- 康复师能接受家长版说明没有改变自己的处方含义。
- 家长完成训练后能明确反馈：是否完成、哪里不舒服、哪里做不下去、是否需要联系康复师。
- 线下试点时，家长端不再只是“报告查看器”，而是“家庭执行助手”。
