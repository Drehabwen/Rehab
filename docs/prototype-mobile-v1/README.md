## 开发顺序
1. PWA 壳 + 今日接诊
2. 新建接诊 + 量表（点选 / 校验）
3. 报告
4. 同步队列
5. 语音问诊
6. 患者档案 + 历史导入

## 交互约束（界面已锁定）
- 量表不打字：仅点选，上次值虚线提示
- 语音要点独立可点，不依赖转写
- 待同步是显式状态，必须可见
