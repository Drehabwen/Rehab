## 示例：usePostureWS

### 1. 功能概述
管理姿态分析的 WebSocket 连接，处理实时骨骼点数据和评估报告

### 2. 核心函数

#### 函数名：connect
- **位置**：`src/hooks/usePostureWS.ts:45`
- **输入**：无
- **输出**：WebSocket 连接
- **逻辑**：
  1. 创建 WebSocket 连接
  2. 设置 onopen/onmessage/onclose 回调
  3. 处理不同类型的消息
- **关键代码**：
```typescript
const connect = useCallback(() => {
  ws.current = new WebSocket(WEBSOCKET_URL);
  
  ws.current.onopen = () => {
    console.log('WebSocket connected');
    setIsConnected(true);
  };
  
  ws.current.onmessage = (event) => {
    const data = JSON.parse(event.data);
    // 处理不同类型的消息
    switch(data.type) {
      case 'POSTURE_RESULT':
        onResults(data);
        break;
      case 'STREAM_CHUNK':
        // 处理流式报告
        break;
    }
  };
}, []);
```

### 3. 数据流
```
摄像头帧 → MediaPipe 处理 → WebSocket 发送 → 后端分析 → 返回结果 → 更新 UI
```

### 4. 关键技术点
- 使用 `useRef` 保持 WebSocket 实例
- 使用 `useCallback` 优化回调函数
- 自动重连机制

### 5. 可能的问题
- Q: 如果 WebSocket 断开怎么办？
- A: 有重连机制，最多重试 3 次
- Q: 为什么不用 Socket.IO？
- A: 项目需要简单，原生 WebSocket 足够

### 6. 我的理解
这个 hook 封装了 WebSocket 的所有细节，让组件可以专注于业务逻辑
